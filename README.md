# Zain Yarfa Mubarok — 2026 Portfolio App 🚀

Website portofolio interaktif berbasis **React + Vite** dengan animasi 3D Lanyard ID Card, React Bits, Skiper UI, dan skema warna **American Retro Vintage** (`#DCC9A9`, `#B83A2D`, `#4E6851`, `#1A1918`).

---

## 🛠️ Cara Menjalankan Project di Lokal

Jika baru saja di-clone dari GitHub (`Knowll322/porto_2026`), ikuti langkah-langkah berikut:

### 1. Clone Repository
```bash
git clone https://github.com/Knowll322/porto_2026.git
cd porto_2026
```

### 2. Install Dependencies (Wajib!)
Sebelum menjalankan `npm run dev`, pastikan untuk menginstall seluruh *dependencies* terlebih dahulu:
```bash
npm install
```

### 3. Jalankan Development Server
```bash
npm run dev
```
Buka browser di alamat: **`http://localhost:5173`** (atau port yang tertera pada terminal).

---

## 🚀 Cara Build & Preview

### Build untuk Produksi:
```bash
npm run build
```

### Preview Hasil Build:
```bash
npm run preview
```

---

## 🌐 Cara Deploy Gratis ke Vercel / Netlify

### Deploy di Vercel:
1. Hubungkan akun GitHub Anda ke [Vercel](https://vercel.com).
2. Impor repositori **`Knowll322/porto_2026`**.
3. Pilihan Framework preset: **Vite**.
4. Klik **Deploy**!

---

## 🎨 Spesifikasi Teknologi & Komponen
- **Framework**: React 19 + Vite 8
- **3D Physics Lanyard ID Card**: `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`, `meshline`, `three`
- **UI Components**: React Bits (`CardNav`, `LineSidebar`, `FaultyTerminal`, `BorderGlow`, `CurvedInput`, `OptionWheel`, `AccordionGallery`) & Skiper UI (`Skiper31`)
- **Theme**: American Retro Vintage Palette (Default Light Mode `#DCC9A9` & Toggle Dark Mode `#1A1918`)
